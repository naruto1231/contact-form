# Contact Form

シンプルな問い合わせフォームです。PHPで送信されたメッセージを受け取り、テキストファイルに保存します。

## 概要

誰でもメッセージを送信できる簡易的な問い合わせフォームのサンプルです。

## 構成ファイル

- `write.php` — フォームから送信されたメッセージを受け取り、保存する処理
- `write.txt` — 送信されたメッセージの保存先

## 動作環境

PHP が実行できる環境が必要です。

```bash
php -S localhost:8000
```
